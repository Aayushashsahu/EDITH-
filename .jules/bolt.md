## 2024-05-28 - Optimize Ollama client connection pooling and embedding batching
**Learning:** For extensive backend performance improvements in API integration, creating a new `aiohttp.ClientSession` on every API call acts as a heavy performance bottleneck due to repeatedly negotiating TCP limits. Additionally, for massive parallel operations such as massive vector embed requests to local Ollama clients via `asyncio.gather()`, executing all requests at once could cause system unresponsiveness.
**Action:** Use a single, cached `aiohttp.ClientSession` internally (such as inside a `get_session` property on API client classes), and when executing large amounts of parallel local LLM/embedding operations across texts/chunks, limit concurrency by executing batches sequentially (e.g. `batch_size = 5`).
